# Hexapod · нижний уровень управления

**Прошивка STM32F103 для замкнутого управления приводами: контуры тока, скорости и положения, фильтрация АЦП, энкодеры и CAN.**

[English](README.md) | Русский

Это **нижний Embedded-уровень** многоуровневой системы управления гексаподом. STM32F103C8T6 выполняет измерения и задачи управления вблизи исполнительных механизмов. В прошивке реализовано несколько вариантов подчинённого регулирования, а не один фиксированный ПИД-регулятор.

## Возможности

- **Два канала управления двигателями** на один контроллер: ШИМ и направление вращения.
- **Контуры по положению, скорости и току**, включая различные комбинации регуляторов, выбираемые в `pid_enable()`.
- **АЦП и DMA:** измерение электрических величин, фильтрация, пересчёт отсчётов.
- **Таймеры и энкодеры:** расчёт скорости и угла, обработка прерываний.
- **Обмен по CAN:** функции передачи команд и телеметрии на соседний уровень.
- **Работа с абсолютным углом:** расчёт и процедуры калибровки.

## Структура регулирования

```text
Задание от верхнего уровня / CAN
               │
               ▼
       Контур положения
               │
               ▼
        Контур скорости  ── обратная связь по энкодеру
               │
               ▼
          Контур тока    ── АЦП + DMA + фильтрация
               │
               ▼
       ШИМ / драйвер    ── два канала приводов
```

Реализованы и сокращённые цепочки: скорость + ток, только положение, только ток и др. Выбор режимов находится в [`Core/Src/main.c`](Core/Src/main.c), регуляторы — в [`Core/Src/motor_CONTROL.c`](Core/Src/motor_CONTROL.c).

## Аппаратная часть и инструменты

- **МК:** STM32F103C8T6; настройки периферии — `F103C8T6_with_help.ioc`.
- **Среда:** STM32CubeIDE, проект на STM32 HAL.
- **Периферия:** ADC, DMA, TIM, GPIO, CAN, CRC.
- **Для испытаний:** совместимый силовой драйвер, измерение тока, датчики положения, блок питания и программатор (например, ST-LINK).

Схемы подключения и полного описания конкретной платы в архиве нет. Сверяйте реальные выводы с `.ioc` и собственной схемотехникой.

## Сборка и прошивка

1. Импортируйте проект в STM32CubeIDE как существующий проект (`.project`, `.cproject` в корне).
2. Проверьте конфигурацию выводов и периферии в [`F103C8T6_with_help.ioc`](F103C8T6_with_help.ioc).
3. До подачи питания проверьте `number_bridge`, коэффициенты регуляторов, калибровку датчиков тока и ограничения ШИМ.
4. Соберите конфигурацию `Debug` средствами STM32CubeIDE.
5. Прошейте и отладьте контроллер совместимым программатором.

В архиве уже присутствуют файлы из `Debug/`, однако для собственного устройства лучше **пересобрать прошивку из исходников**. Отдельной программы, запускаемой на ПК без аппаратуры, нет.

## Структура исходников

| Файл | Назначение |
|---|---|
| `Core/Src/main.c` | Инициализация, основной цикл, выбор режима управления |
| `Core/Src/motor_CONTROL.c` | Подчинённое регулирование и ШИМ |
| `Core/Src/motor_FILTERS.c` | Фильтрация, ток/напряжение, скорость |
| `Core/Src/angle_ABSOLUTE.c` | Абсолютный угол и калибровка |
| `Core/Src/can_TRANSMIT_RECEIVE.c` | Передача, приём и упаковка CAN-данных |
| `Core/Src/stm32f1xx_it.c` | Обработчики прерываний |
| `Core/Inc/main.h` | Общие структуры и константы |
| `Drivers/` | STM32 HAL и CMSIS |

## Место в системе гексапода

```text
Hexapod_3_High_Level   алгоритмы движения и походки
           │
Hexapod_2_Middle_Level команды, ROS 2, одометрия, CAN
           │
Hexapod_1_Low_Level    обратные связи и приводы  ← этот репозиторий
```

Это три самостоятельных репозитория, описывающие инженерную архитектуру; единой готовой сборки для запуска всей системы в архиве нет.

## Статус и замечания

- Исследовательская прошивка для физического прототипа.
- Функции CAN есть, но часть инициализации/передачи в `main.c` в сохранённой версии закомментирована. Перед интеграцией проверьте этот участок.
- **Осторожно:** прошивка управляет реальными двигателями. При испытаниях необходимы ограничения тока, безопасное положение механики и возможность аварийного останова.
- Отдельной лицензии проекта в корне нет; для библиотек ST действуют их собственные условия.
