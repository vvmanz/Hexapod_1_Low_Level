# Hexapod_1_Low_Level

**Моторный уровень шестиногого робота: каскадный регулятор тока, скорости и угла для двух приводов постоянного тока на STM32F103C8T6, управление по CAN.**

[English](README.md) | Русский

```
 Hexapod_3_High_Level   ROS 2 / Gazebo: походки, CPG, навигация
          │  топики ROS 2
 Hexapod_2_Middle_Level STM32F446RE: FreeRTOS + micro-ROS по Ethernet, одометрия
          │  CAN (2 шины)
 ► Hexapod_1_Low_Level  3 × STM32F103C8T6, по 2 мотора = 6 приводов ног         ◄ вы здесь
```

Это прошивка одной моторной платы. Шесть ног приводят три одинаковые платы, по два мотора на плату; на всех работает один
и тот же код, а `number_bridge` в `Core/Src/main.c` (1, 2 или 3) задаёт номер платы и её CAN-адреса. Каждый мотор
замкнут тремя вложенными контурами: ток (быстрый, внутренний), скорость и угол (внешние). Мастер присылает по CAN целевые
углы, ограничения и коэффициенты регуляторов и получает обратно угол, скорость и ток обоих моторов.

## Возможности

* **Каскадное регулирование** каждого привода: внутри контур тока, вокруг него контур скорости, снаружи контур угла, у
  каждого свои коэффициенты (`kp/ki` для тока и скорости, `kp/ki/kd` для угла), их можно менять на ходу по CAN.
* **Выбираемая структура**: 3-битное поле `system_type` в кадре настроек для каждого мотора выбирает, какие контуры
  замкнуты: 0 угол → скорость → ток, 1 угол → скорость, 2 угол → ток, 3 только угол, 4 скорость → ток, 5 только
  скорость, 6 только ток (`pid_*` в `motor_CONTROL.c`); так можно настраивать контуры по одному.
* **Тайминги**: ШИМ работает на 6 кГц (TIM3, ядро 72 МГц), контур тока дискретизирован тем же шагом 1/6000 с; скорость и
  угол оцениваются каждые 5 мс (200 Гц).
* **Измерение тока и напряжения** АЦП, запускаемым таймером ШИМ и читаемым через DMA: отсчёты синхронны с коммутацией и не
  занимают процессор; каналы датчиков тока чистит медианный фильтр по трём отсчётам.
* **Интерфейс энкодера** на аппаратных таймерах (TIM1, TIM2 в режиме энкодера) с обработкой переполнений; значение
  пересчитывается в угол выходного вала через передаточное число (26,83).
* **Абсолютный угол** при старте по аналоговым каналам датчика положения через АЦП: нога знает, где она, ещё до
  движения.
* **Узел CAN**: аппаратные фильтры приёма для каждой платы, приём в прерываниях, передача мастеру угла, скорости и
  тока; протокол описан ниже.
* **Проект STM32CubeMX** (`F103C8T6_with_help.ioc`): из него генерируются настройки тактирования, таймеров, АЦП, DMA и
  CAN.

### CAN-адреса

Каждая плата слушает свой блок стандартных ID (два фильтра с маской `0x07E1`, чётные и нечётные ID):

| плата (`number_bridge`) | принимаемые ID | содержимое |
|---|---|---|
| 1 | `0x200`–`0x21F` | `0x200` целевые углы, `0x201` ограничения и прочие настройки, `0x202`, `0x203` … коэффициенты регуляторов |
| 2 | `0x300`–`0x31F` | та же схема |
| 3 | `0x400`–`0x41F` | та же схема |

Плата отвечает углом, скоростью и током двух своих моторов, по два 32-битных значения в кадре. Сторона мастера этого
протокола — в [Hexapod_2_Middle_Level](https://github.com/<your-account>/Hexapod_2_Middle_Level).

## Требования

* STM32CubeIDE (или STM32CubeMX + ARM GCC);
* программатор ST-LINK;
* железо: плата на STM32F103C8T6, два двигателя постоянного тока с энкодерами и измерением тока на H-мосту, CAN-трансивер.

## Установка и прошивка

```bash
git clone https://github.com/<your-account>/Hexapod_1_Low_Level.git
```

1. В STM32CubeIDE: *File → Open Projects from File System…* и выберите папку.
2. В `Core/Src/main.c` замените `number_bridge = 1;` на `1`, `2` или `3` для платы, которую шьёте.
3. *Project → Build*, затем *Run → Debug* (или `Run`) с подключённым ST-LINK.

Повторите со следующим номером для остальных плат. Чтобы поменять выводы, тактирование или периферию, правьте
`F103C8T6_with_help.ioc` и генерируйте код; логика управления лежит в секциях `USER CODE` и переживает перегенерацию.

## Структура репозитория

```
Core/Src/main.c            инициализация и главный цикл: АЦП → ток/напряжение, энкодер → скорость/угол, шаг ПИД
Core/Src/motor_CONTROL.c   семь структур регулятора (pid_angle_speed_curr, pid_speed, pid_curr, ...)
Core/Src/motor_FILTERS.c   АЦП → ток и напряжение с медианным фильтром; счёт энкодеров → скорость и угол
Core/Src/angle_ABSOLUTE.c  начальный абсолютный угол по аналоговым каналам датчика
Core/Src/can*.c            настройка CAN, фильтры, приём и передача
Core/Src/stm32f1xx_it.c    прерывания: переполнения энкодеров, таймеры контуров
Core/Src/tim.c, adc.c      сгенерированная настройка периферии (таймеры, АЦП + DMA)
Core/Src/VARIABLES.c       общее состояние и константы
Core/Inc/main.h            выводы, опорные напряжения, масштаб датчика тока
F103C8T6_with_help.ioc     проект STM32CubeMX
Drivers/                   ST HAL и CMSIS (свои лицензии)
```

## Часть стека Hexapod

| уровень | репозиторий | работает на |
|---|---|---|
| 1 — моторы | **Hexapod_1_Low_Level** | STM32F103C8T6 × 3 |
| 2 — координация | [Hexapod_2_Middle_Level](https://github.com/<your-account>/Hexapod_2_Middle_Level) | STM32F446RE |
| 3 — походки и навигация | [Hexapod_3_High_Level](https://github.com/<your-account>/Hexapod_3_High_Level) | ROS 2 / Gazebo |
